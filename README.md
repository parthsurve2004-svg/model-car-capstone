# Final presentation — compatibility version

Download this branch as a ZIP, extract it, and open **Final_Presentation.pptx** in Microsoft PowerPoint, LibreOffice Impress or Google Slides.

[Download ZIP](https://codeload.github.com/parthsurve2004-svg/model-car-capstone/zip/refs/heads/downloads/presentation-stable)

The presentation contains 16 slides in the required 4:3 institutional format. Every slide is a single fixed image to prevent font substitution, shape movement, transparent-image cropping differences and animation parsing issues. Individual slide text is not editable; detailed speaker notes are retained. No custom animations are included.

This version includes illustrated architecture and explanations of lane detection, obstacle avoidance, pothole detection and traffic-sign recognition. Actual prototype photographs are removed. Quantitative model results are concentrated on the results slide.

The file was opened and rendered through LibreOffice, all 16 pages were compared with the reviewed PDF, and ZIP/package integrity was checked. Testing in Microsoft PowerPoint itself was not available.

This download branch does not modify the project's main branch.
